Things to know

  • The store is wiped when each demo starts, and the chain folder is deleted when you press Ctrl-C. Nothing carries over between runs.
  • demo-synthetic is not wiped. Burst numbers restart at 001 each run, so new files overwrite old ones of the same number; higher-numbered files from an earlier, longer run stay until you delete them.
  • Look, don't edit. Changing a byte in the store by hand is exactly what the Tamper button does, and the next verify or audit flags that item. Reading is harmless, and this page can only read.
  • Private keys are never shown. The chain folder holds the validator's key; this page lists it and refuses to open it.
  • /api/state is the investigator's view. It includes what the investigator's client has decrypted, such as which hex file is which item. The server has none of that.
